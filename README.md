# Đêm Hội Trăng Rằm

Trang sự kiện Trung Thu của Chrono Archive: fanart, quà cho người xem thường xuyên, đĩa nhạc đêm rằm, thả đèn ước nguyện và câu đố đèn.

## Cập nhật nội dung

Mọi thứ nằm trong `trung-thu-data.js`, không cần sửa `index.html`:

- **Fanart:** bỏ ảnh vào `fanart/`, thêm một dòng vào `fanarts`.
- **Người xem thường xuyên:** thêm một dòng vào `regulars`.
- **Đã gửi quà:** đổi `daGui: false` thành `daGui: true`.
- **Nhạc mp3 riêng (không bắt buộc):** bỏ file vào repo, thêm một dòng vào `nhac`.

Không ghi số tài khoản, số điện thoại hay thông tin MoMo vào file này vì nó công khai.
